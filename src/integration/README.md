Foi realizada a integração entre o modelo preditivo XGBoost e o algoritmo de otimização Hill Climbing.

O modelo preditivo foi utilizado para gerar previsões futuras de vendas/clientes, enquanto o algoritmo de otimização utilizou essas previsões para recomendar automaticamente estratégias operacionais.

#######Resultado da otimização##################

O algoritmo Hill Climbing procurou automaticamente a combinação mais eficiente de:

-descontos promocionais
-funcionários experientes
-funcionários juniores

com base nas previsões geradas pelo modelo XGBoost.

O resultado final corresponde ao lucro semanal estimado obtido pela melhor estratégia encontrada durante o processo de otimização.
